# Game Concept

Mystery Player is a daily football history guessing game.

Each puzzle presents a notable match from history. Some players in the lineup are hidden, and the user tries to identify them.

Potential puzzle ingredients:

- Match date, teams, competition, venue, and score.
- Starting lineups and substitutes.
- Player positions and shirt numbers where available.
- Clues such as nationality, club at the time, career hints, or match events.
- Answer normalization for accents, common name variants, and partial names.

Candidate modes:

- Daily Match: one puzzle for everyone each day.
- Archive: browse and play previous matches.
- Hard Mode: no team, position, or clue help.
- Club/Nation Packs: themed collections by team, tournament, or era.
